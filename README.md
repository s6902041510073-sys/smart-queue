# 🎓 Smart Queue (ระบบบัตรคิวตรวจงานและปรึกษาอาจารย์)

ระบบจัดการคิว (Smart Queue) แบบ Real-time ที่ออกแบบมาเพื่อช่วยแก้ปัญหานักศึกษายืนรอต่อคิวส่งงาน หรือปรึกษาอาจารย์เป็นเวลานาน ระบบนี้แบ่งการทำงานเป็น 2 ส่วนหลักคือ **ฝั่งนักศึกษา** (สำหรับจองและดูคิว) และ **ฝั่งครูผู้สอน** (สำหรับเรียกคิวและจัดการตารางเวลา)

## ✨ ฟีเจอร์หลัก (Features)

### 🧑‍🎓 ฝั่งนักศึกษา (Student Panel)
- **จองคิวแบบแยกอาจารย์:** เลือกอาจารย์ที่ต้องการพบและจองคิวได้ทันที
- **เช็คสถานะ Real-time:** ดูจำนวนคิวที่รออยู่ด้านหน้า และอัปเดตสถานะอัตโนมัติ (Polling) ทุกๆ 3 วินาที
- **ดูตารางเวลาอาจารย์:** ตรวจสอบตารางที่อาจารย์ว่างรับปรึกษาในแต่ละวันได้
- **ระบบแจ้งเตือนเมื่อถึงคิว:** หน้าจอจะกะพริบแจ้งเตือนเมื่ออาจารย์กด "เรียกคิว"
- **ยกเลิกคิว:** สามารถกดยกเลิกคิวของตัวเองได้หากเปลี่ยนใจ

### 👨‍🏫 ฝั่งครูผู้สอน (Teacher Dashboard)
- **ระบบเข้าสู่ระบบ (Login):** อาจารย์แต่ละท่านมีรหัสผ่านส่วนตัวเพื่อเข้าสู่แดชบอร์ดของตนเอง
- **ระบบจัดการคิว (FIFO):**
  - กดปุ่ม **"เรียก"** เพื่อให้นักศึกษาเดินมาที่โต๊ะ
  - กดปุ่ม **"เสร็จสิ้น"** เมื่อตรวจงานเรียบร้อย (คิวจะถูกบันทึกสถิติ)
  - กดปุ่ม **"ข้าม"** หากเรียกแล้วนักศึกษาไม่มา
- **ระบบจัดการตารางเวลา:** สามารถเข้าไปตั้งค่า วัน และ เวลา (Start - End time) ที่สะดวกให้นักศึกษาเข้ามาพบได้ด้วยตัวเอง
- **ระบบรีเซ็ตคิว:** สามารถกดปุ่มล้างคิวทั้งหมดของวันนั้นๆ เพื่อเตรียมพร้อมสำหรับวันใหม่

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **Frontend & Backend:** [Next.js 14](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (เน้นดีไซน์ Glassmorphism และ Gradients)
- **Database ORM:** [Prisma](https://www.prisma.io/)
- **Database:** PostgreSQL (สำหรับ Production บน Vercel) / SQLite (สำหรับ Local Development)
- **Deployment:** [Vercel](https://vercel.com/) (Hosting) + [Supabase](https://supabase.com/) (PostgreSQL Database)

## 🚀 วิธีการติดตั้งและรันบนเครื่องตัวเอง (Local Development)

1. **โคลนโปรเจกต์**
   ```bash
   git clone https://github.com/s6902041510073-sys/smart-queue.git
   cd smart-queue
   ```

2. **ติดตั้ง Dependencies**
   ```bash
   npm install
   ```

3. **ตั้งค่า Database**
   เข้าไปแก้ไขไฟล์ `.env` (หากไม่มีให้สร้างใหม่) และใส่ตั้งค่าดังนี้:
   ```env
   # สำหรับรันด้วย SQLite บนเครื่อง (แนะนำสำหรับเทส)
   DATABASE_URL="file:./dev.db"
   ```
   *(หมายเหตุ: ต้องแก้ `provider` ในไฟล์ `prisma/schema.prisma` ให้เป็น `sqlite` ก่อนรันคำสั่งถัดไป หากต้องการรันบนเครื่อง)*

4. **สร้างตารางใน Database**
   ```bash
   npx prisma generate
   npx prisma db push
   ```

5. **รันเซิร์ฟเวอร์จำลอง**
   ```bash
   npm run dev
   ```
   เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

6. **สร้างข้อมูลจำลอง (Seed Data)**
   เปิดลิงก์ `http://localhost:3000/api/seed` 1 ครั้งเพื่อสร้างรายชื่ออาจารย์จำลอง (พร้อมรหัสผ่าน 1111, 2222, 3333)

## ☁️ วิธีการนำขึ้นเซิร์ฟเวอร์จริง (Deploy to Vercel)

โปรเจกต์นี้ตั้งค่า `provider = "postgresql"` ไว้ในไฟล์ Prisma เพื่อให้พร้อมสำหรับรันบน Vercel 

1. นำโค้ดขึ้น GitHub 
2. สมัครใช้งาน [Supabase](https://supabase.com/) และสร้าง Database รหัสผ่าน
3. ก๊อปปี้ลิงก์ `DIRECT_URL` (Port 5432) จาก Supabase
4. เข้าไปสร้างโปรเจกต์ใน [Vercel](https://vercel.com/) และตั้งค่า **Environment Variables**:
   - `DATABASE_URL` = ลิงก์จาก Supabase (ใส่รหัสผ่านให้เรียบร้อย)
5. ใน Vercel ตั้งค่า **Build Command** เป็น:
   ```bash
   npx prisma generate && npx prisma db push && next build
   ```
6. กด **Deploy**
7. เมื่อเว็บรันเสร็จ ให้เข้าไปที่ `https://ชื่อเว็บของคุณ.vercel.app/api/seed` 1 ครั้ง เพื่อสร้างข้อมูลอาจารย์บนเซิร์ฟเวอร์จริง
